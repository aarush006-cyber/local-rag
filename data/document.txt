AI and RAG Engineering Reference Corpus

This large synthetic text corpus is intended for experimenting with
retrieval-augmented generation. It contains related concepts,
definitions, distinctions, and engineering details so that different
retrieval strategies can be tested.

Artificial Intelligence is the field of building systems that perform
tasks associated with perception, reasoning, learning, planning,
language understanding, and decision making. Narrow AI focuses on
defined tasks, while general intelligence is a broader research concept.
AI systems should be evaluated for accuracy, robustness, reliability,
bias, calibration, and behavior under distribution shift.

3. Linear Regression

Linear regression predicts a continuous target using weighted input
features. Ordinary least squares minimizes squared residuals. Mean
absolute error measures average absolute error, root mean squared error
emphasizes large errors, and R-squared compares explained variance with
a mean-prediction baseline.

14. Embeddings and Semantic Search

Text embedding models map text into vector spaces. Semantic search

Embedding quality depends on the model, domain, preprocessing, chunk

15. Retrieval-Augmented Generation

Retrieval-Augmented Generation combines information retrieval with
language generation. Documents are loaded, divided into chunks,
embedded, indexed, and searched using a user query. Retrieved evidence
is inserted into a prompt and supplied to a language model. RAG has two
major jobs: retrieval and generation.

16. Chunking

Chunking divides source documents into smaller units for indexing and
retrieval. Fixed-size chunking uses character or token limits.
Overlapping chunks repeat boundary content. Sentence-based chunking
preserves sentence boundaries. Recursive chunking uses hierarchical
separators. Semantic chunking groups text according to meaning. Chunk
size creates a trade-off between context and retrieval precision.

25. RAG Prompting

A RAG prompt should clearly separate instructions, retrieved context,
and the user question. Retrieved documents should generally be treated
as untrusted data because they may contain prompt injection attempts. A
system can instruct the model to answer only from supplied evidence and
to admit when evidence is insufficient.

Retrieval metrics include recall at K, precision at K, mean reciprocal
rank, and normalized discounted cumulative gain. Generation evaluation
can consider correctness, faithfulness, relevance, completeness, and
citation quality. A fixed evaluation set is essential for meaningful
comparisons.

data, and tool outputs as potentially untrusted. Common risks include
prompt injection, data leakage, excessive permissions, malicious
documents, and secret exposure. API keys should be stored outside source

inputs, outputs, constraints, evaluation criteria, latency expectations,
and cost before choosing components. Modular pipelines make

reranking, prompting, generation, and evaluation can be changed
